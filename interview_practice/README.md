# Interview Practice - Starter Code

Python starter files for the programming problems in the practice
assignment (system design problems in Part 3 are discussion-only and
have no file here).

| File | Problem |
|---|---|
| `01_inventory_system.py` | 1.1 Inventory and Reorder System |
| `02_recipe_shopping_list.py` | 1.2 Recipe and Shopping List Generator |
| `03_gas_station.py` | 2.1 Greedy: Gas Station |
| `04_campaign_reach_bfs.py` | 2.2 Graph / BFS: Campaign Reach Simulation |
| `05_budget_allocation_knapsack.py` | 2.3 Dynamic Programming: Budget Allocation |
| `06_click_fraud_detector.py` | 2.4 Sliding Window: Click Fraud Detector |
| `07_bid_hierarchy_rollup.py` | 2.5 Trees: Bid Hierarchy Rollup |

Each file has the problem statement as a docstring, function or class
stubs to fill in, and a `__main__` block with basic checks you can run
directly:

```
python 03_gas_station.py
```

Checks use plain `assert` statements. If your implementation is
correct, the script prints `All basic checks passed.` and exits
cleanly; otherwise it raises an `AssertionError` or `NotImplementedError`.
